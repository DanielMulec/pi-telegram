# Fork Membrane Acquisition Tracer Evidence

**Target:** `@llblab/pi-telegram` fork (`fork-membrane-v1`)
**Specification:** Ticket #44 / Spec #43 / ADR-0006
**Environment:** Real Pi CLI 0.84.2 in RPC mode with a disposable `PI_CODING_AGENT_DIR`, `PI_OFFLINE=1`, and no credentials or production stores.

## Command

```bash
npm run trace:fork
```

The tracer starts `pi --mode rpc --no-session --no-extensions -e <temporary-extension>`. The temporary extension drives the fork's real bridge from a non-command input hook and records booleans and the projected lifecycle surface. The private bridge token is observed by Pi's public input event only if Pi fails to dispatch it as a command; no transcript or host state is read.
