# Fork Membrane Acquisition Tracer Evidence

**Target:** `@llblab/pi-telegram` fork (`fork-membrane-v1`)
**Specification:** Ticket #44 / Spec #43 / ADR-0006
**Environment:** Real Pi CLI in RPC mode with disposable `PI_CODING_AGENT_DIR` and `PI_CODING_AGENT_SESSION_DIR`, `PI_OFFLINE=1`, no tmux, credentials, or production stores.

## Command

```bash
npm run trace:fork
```

The tracer starts `pi --mode rpc --no-session --no-extensions -e <temporary-extension>`, sends two public RPC `prompt` messages, and ends with a public RPC `shutdown`. The temporary extension imports the fork's narrow projection helpers. It records only booleans and counts; session identifiers and filesystem paths never enter committed output.
